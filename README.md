# Rain_prediction_AUSTRALIA
This project predicts whether it will rain tomorrow in Australia.

## About
- Data: weatherAUS.csv (daily weather records)
- Model: Artificial Neural Network (ANN) built with Keras
- Notebook: Rain_pred_ANN.ipynb (training and analysis)
- App: app.py (makes predictions)

## Tools Used
Python, Pandas, Scikit-learn, TensorFlow, GitHub Actions
